# Grain & Gable Carpentry

Static one-page site. Open `index.html` in a browser. The repository root deploys on Vercel with no build step.

Photos in `images/` are JPEG and WebP at 480, 768, and 1152 pixels wide. The original camera files are not in this repository.

Fonts in `fonts/` are Fraunces and Atkinson Hyperlegible, both under the SIL Open Font License. License texts sit beside the files.
